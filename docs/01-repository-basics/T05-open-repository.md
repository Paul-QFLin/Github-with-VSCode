## 任務目標

使用 VS Code 開啟已存在的本機 Repository，並檢查工作區與 Source Control。

## 學習重點

Open Folder / Open Repository

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] VS Code 開啟正確的 Repository 根目錄，並能顯示版本控制狀態。
