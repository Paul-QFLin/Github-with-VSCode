# 第二階段：檢視與回復版本

在第一階段學會 Commit、Push、Pull 與衝突處理後，進一步看懂變更與歷史紀錄，並學習安全地處理不需要的修改。

## 規劃中的任務

- **T05：查看變更與版本紀錄** — 使用 VS Code 查看修改前後的差異、已暫存的內容與 Commit History；在 GitHub 上查看版本紀錄。
- **T06：回復與放棄修改** — 分辨尚未提交與已提交的修改，認識放棄修改和以新 Commit 回復的差別；操作前確認可能遺失的內容。

以上是新課程規劃，完整講義尚未製作。第一階段的 [T02](../01-基礎的儲存庫操作-repository-basics/T02-提交Commit一個版本.md) 與 [T03](../01-基礎的儲存庫操作-repository-basics/T03-推送至遠端Push與從遠端拉取Pull.md) 已涵蓋暫存、提交、推送與拉取的基本操作。
