# 第二階段：版本檢視與協作

接續第一階段的基本操作，先學習處理衝突，再查看版本差異、管理提交紀錄、回復修改，最後認識分支與 Pull Request 協作。

## 課程安排

- **T04：衝突發生的處理** — 理解衝突原因並在 VS Code 實際處理。這是本階段第一課，請先完成第一階段 T00～T03。
- **T05：查看變更與版本紀錄** — 使用 VS Code 查看修改前後的差異、已暫存的內容與 Commit History；在 GitHub 上查看版本紀錄。
- **T06：回復與放棄修改** — 分辨尚未提交與已提交的修改，認識放棄修改和以新 Commit 回復的差別；操作前確認可能遺失的內容。
- **T12：建立、切換與合併分支** — 認識分支的用途，在 VS Code 建立與切換分支、提交修改並合併；遇到衝突時運用 T04 的處理方式。
- **T13：使用 Pull Request 協作** — 推送分支到 GitHub、建立 Pull Request、查看與討論修改，確認後合併並取得結果。

T04 已完成講義；T05、T06、T12 與 T13 是新課程規劃，完整講義尚未製作。第一階段的 [T02](../01-基礎的儲存庫操作-repository-basics/T02-提交Commit一個版本.md) 與 [T03](../01-基礎的儲存庫操作-repository-basics/T03-推送至遠端Push與從遠端拉取Pull.md) 已涵蓋暫存、提交、推送與拉取的基本操作。
