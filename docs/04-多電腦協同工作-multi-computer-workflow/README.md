# 第四階段：多電腦協同工作

運用第一階段的 Clone、Push、Pull 與衝突處理，在不同電腦之間接續工作，並整理操作環境。

## 規劃中的任務

- **T10：在不同電腦接續工作** — 在另一台電腦複製儲存庫，以 Fetch／Pull、修改、Commit、Push 的流程接續工作；管理多個專案，遇到衝突時回顧 T04。
- **T11：同步 VS Code 操作環境** — 認識 Settings Sync、設定與擴充功能的同步範圍，分辨編輯器設定同步與專案檔案的 Git 同步。
