# T19：在 A 電腦修改程式，在 B 電腦繼續工作

> 所屬階段：[回到第四階段：多電腦協同工作](README.md) · [課程總覽](../../README.md)

## 任務目標

在 A 電腦提交並推送修改，再於 B 電腦 Pull 後繼續編輯。

## 學習重點

Push / Pull

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] 兩台電腦的工作都已透過遠端同步，且 B 電腦接續的是最新版本。
- [ ] 能說明本任務使用的功能及其適用情境。
