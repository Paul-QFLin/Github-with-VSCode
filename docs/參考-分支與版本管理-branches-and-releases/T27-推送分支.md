# T27：將分支上傳至 GitHub

> 所屬資料：[回到分支與版本管理舊講義參考](README.md) · [課程總覽](../../README.md)

## 任務目標

將本機開發分支推送到 GitHub，並確認遠端分支已建立或更新。

## 學習重點

Push Branch

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] GitHub 上可找到正確分支，且遠端分支包含預期提交。
- [ ] 能說明本任務使用的功能及其適用情境。
