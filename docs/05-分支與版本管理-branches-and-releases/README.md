# 第五階段：分支與版本管理

在熟悉基本版本控制後，學習使用分支隔離工作，並透過 GitHub Pull Request 討論與整合修改。

## 規劃中的任務

- **T12：建立、切換與合併分支** — 認識分支的用途，在 VS Code 建立與切換分支、提交修改並合併；遇到衝突時運用 T04 的處理方式。
- **T13：使用 Pull Request 協作** — 推送分支到 GitHub、建立 Pull Request、查看與討論修改，確認後合併並取得結果。

以上是新課程規劃，完整講義尚未製作。回復與放棄修改安排在[第二階段 T06](../02-版本控制-version-control/README.md)。
