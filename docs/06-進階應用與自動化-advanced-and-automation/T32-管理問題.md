# T32：使用 GitHub 管理程式問題

> 所屬階段：[回到第六階段：進階應用與自動化](README.md) · [課程總覽](../../README.md)

## 任務目標

建立一個描述明確的 Issue，加入重現資訊、標籤或負責人以利追蹤。

## 學習重點

Issues

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] Issue 能讓其他協作者理解問題、預期結果與後續處理方式。
- [ ] 能說明本任務使用的功能及其適用情境。
