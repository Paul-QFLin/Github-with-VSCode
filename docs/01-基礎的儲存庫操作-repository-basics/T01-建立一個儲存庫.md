# T01：建立一個新的 Repo

> 所屬階段：[回到第一階段：建立與取得 Repo](README.md) · [課程總覽](../../README.md)

## 任務目標

在 GitHub 建立一個新的 Repository，並確認名稱、可見性與初始檔案設定。

## 學習重點

GitHub Repository

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] 能在 GitHub 找到新建立的 Repository，並辨識其遠端網址。
- [ ] 能說明本任務使用的功能及其適用情境。
