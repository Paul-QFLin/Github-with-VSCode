# T33：使用 GitHub 管理專案工作

## 任務目標

建立或使用 GitHub Project，將 Issues 或 Pull Requests 加入工作流程並更新狀態。

## 學習重點

Projects

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] 工作項目與狀態能反映目前進度，且可追溯至相關 Issue 或 Pull Request。
- [ ] 能說明本任務使用的功能及其適用情境。
