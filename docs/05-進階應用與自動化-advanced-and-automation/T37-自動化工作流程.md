# T37：使用 GitHub Actions 執行自動化工作

> 所屬階段：[回到第五階段：進階應用與自動化](README.md) · [課程總覽](../../README.md)

## 任務目標

為練習 Repository 設定一個簡單的 GitHub Actions 工作流程，並檢視執行結果。

## 學習重點

CI / CD

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] Workflow 能依設定觸發，且可在 GitHub Actions 頁面查看成功或失敗的工作紀錄。
- [ ] 能說明本任務使用的功能及其適用情境。
