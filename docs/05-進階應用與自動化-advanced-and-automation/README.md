# 第五階段：進階應用與自動化

運用 GitHub 整理專案資訊、管理工作與發布版本，並初步認識自動化。

## 規劃中的任務

- **T14：撰寫專案說明文件** — 使用 README 說明專案用途、使用方法與基本 Markdown 格式。
- **T15：使用 Issues 與 Projects 管理工作** — 記錄問題與待辦事項，並使用 Projects 整理工作進度。
- **T16：標記與發布版本** — 認識 Tag 與 Release 的用途，標記並發布可供使用者辨識的版本。
- **T17：使用 GitHub Actions 自動化工作** — 認識事件、工作流程與執行結果，實作安全的自動化範例；討論自動提交或更新儲存庫時的權限與風險。

以上是新課程規劃，完整講義尚未製作。專案移轉安排在[第三階段 T09](../03-檔案與儲存庫管理-files-and-repositories/README.md)。
