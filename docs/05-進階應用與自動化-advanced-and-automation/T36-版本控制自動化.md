## 任務目標

整理需要自動化的本機 Git 操作，明確定義觸發時機與預期結果，再於測試 Repository 驗證。

## 學習重點

Git Automation

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] 自動化流程只處理預期檔案與遠端，且能確認執行結果及錯誤狀態。
- [ ] 能說明本任務使用的功能及其適用情境。
