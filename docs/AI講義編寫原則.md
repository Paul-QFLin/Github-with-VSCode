# AI 講義編寫原則

本文件規範本課程 AI 講義的撰寫方式，確保各篇內容一致、易懂且可實際操作。

## 內容原則

- 使用繁體中文，以初學者能理解的方式解釋 Git、GitHub 與 VS Code 概念。
- 每篇聚焦一個任務，標題包含任務編號及清楚的中文名稱。
- 以實際操作為主；保留必要的產品名稱、介面標籤、指令與程式碼原文，並在首次出現時補充中文說明。
- 操作步驟依實際順序撰寫，說明必要的前置條件及預期結果。
- 外部網址一律在新分頁開啟，保留原講義頁面；使用 HTML 連結並設定 `target="_blank"` 與 `rel="noopener noreferrer"`。站內連結則維持一般連結行為。
- 涉及刪除、覆寫、放棄修改或推送等可能造成影響的操作時，先提醒讀者確認目標與變更內容。
- 不臆測未確認的介面或功能；若操作方式可能因版本或平台而不同，應明確說明。
- 使用簡潔、可驗證的敘述，避免含糊的「應該成功」等描述。

## 任務講義結構

任務講義依序包含以下部分：

1. **任務目標**：說明要完成什麼。
2. **學習重點**：列出本任務會使用的功能或概念。
3. **實作練習**：提供依序可執行的操作指引。
4. **完成檢查**：列出可觀察、可確認的結果。

篇幅可依任務需要調整；若需補充背景、疑難排解或注意事項，應放在最相關的步驟附近。
