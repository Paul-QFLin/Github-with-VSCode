# T10：取得 GitHub 上的最新版本

> 所屬階段：[回到第二階段：基本版本控制](README.md) · [課程總覽](../../README.md)

## 任務目標

在本機工作目錄乾淨時，從遠端取得並整合最新提交。

## 學習重點

Pull

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] 本機分支已包含預期的遠端提交，且理解 Pull 會更新目前分支。
- [ ] 能說明本任務使用的功能及其適用情境。
