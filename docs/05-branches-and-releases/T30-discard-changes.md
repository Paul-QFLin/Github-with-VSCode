# T30：放棄尚未提交的修改

> 所屬階段：[回到第五階段：分支與版本管理](README.md) · [課程總覽](../../README.md)

## 任務目標

在可丟棄的練習修改上使用 Discard Changes，操作前先確認檔案與差異。

## 學習重點

Discard Changes

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] 只放棄指定的未提交修改，並了解此操作可能無法復原。
- [ ] 能說明本任務使用的功能及其適用情境。
