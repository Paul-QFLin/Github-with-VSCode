# T14：刪除或重新命名 Repo 中的檔案

> 所屬階段：[回到第三階段：檔案與 Repo 管理](README.md) · [課程總覽](../../README.md)

## 任務目標

在 Repository 中重新命名或刪除檔案，並檢視 Git 顯示的變更。

## 學習重點

Delete / Rename

## 實作練習

1. 在測試 Repository 或可安全操作的練習環境中完成上述任務。
2. 檢查操作前後的檔案、分支或 GitHub 狀態，確認結果符合預期。
3. 記錄遇到的問題與解決方式，並在繼續下一步前確認沒有未預期的修改。

## 完成檢查

- [ ] 檔案異動已被 Git 正確辨識，且沒有誤刪其他資料。
- [ ] 能說明本任務使用的功能及其適用情境。
