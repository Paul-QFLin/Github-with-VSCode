# 第三階段：檔案與 Repo 管理

學習管理儲存庫中的檔案、追蹤規則與遠端位置，並了解移轉專案時需要注意的事情。

## 規劃中的任務

- **T07：管理儲存庫中的檔案** — 新增、刪除與重新命名檔案，認識未追蹤與已追蹤的狀態，並選擇要提交的變更。
- **T08：忽略不需要追蹤的檔案** — 使用 `.gitignore` 排除暫存檔、產生的檔案與敏感資料；理解忽略規則不會自動移除已追蹤的檔案。
- **T09：管理遠端位置與移轉專案** — 查看及修改遠端網址，辨別修改遠端位置與移轉專案的差異，確認目標與既有資料後再操作。

以上是新課程規劃，完整講義尚未製作。
